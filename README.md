# Aperçu de test - Accompagnement Titres

Page d'aperçu du site d'accompagnement aux démarches administratives, publiée
uniquement pour une validation visuelle.

- `index.html` - la maquette complète, en un seul fichier.
- `.nojekyll` - servir les fichiers tels quels, sans traitement Jekyll.

## Avertissements

- **Coordonnées fictives** : le téléphone `01 99 00 12 34` appartient à la plage
  réservée par l'ARCEP à la fiction ; l'adresse e-mail utilise le domaine réservé
  `.example`. Aucun message ne peut y aboutir.
- **Pages légales vides** : mentions légales, confidentialité et conditions de service
  sont des emplacements à rédiger avec le client. Aucun contenu juridique n'est inventé.
- **Formulaire inerte** : il valide la saisie et affiche une confirmation dans le
  navigateur. Aucun envoi, aucune base de données, aucun paiement.
- **Page non indexable** : la balise `noindex, nofollow` empêche les moteurs de recherche
  de la référencer. Elle est à retirer avant une mise en ligne définitive.
- **Aperçu public par lien** : toute personne possédant l'adresse peut la consulter.
- Aucune validation visuelle n'a encore été faite : la page attend votre contrôle.

Ce dépôt ne contient volontairement que le site. L'étude de concurrence, l'architecture
technique, la proposition de première version et le journal de projet restent dans le
dépôt privé du projet.
